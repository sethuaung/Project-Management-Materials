## 📊 **Business Analyst Life Cycle – Seven Phases**

The Life Cycle ensures that every project moves from vision to validation in a structured way, balancing business goals with technical execution.

**Initiation → Planning → Analysis → Design → Implementation → Testing → Closure**

Each arrow represents progression and feedback loops, ensuring continuous stakeholder engagement and alignment.

```
 ┌─────────────────────────────┐
 │ Initiation                  │
 │ - Identify problems/opportunities
 │ - Define scope & objectives
 └───────────────┬─────────────┘
                 ↓
 ┌─────────────────────────────┐
 │ Planning                    │
 │ - Strategy for requirements
 │ - Workshops, interviews, surveys
 └───────────────┬─────────────┘
                 ↓
 ┌─────────────────────────────┐
 │ Analysis                    │
 │ - Gather detailed requirements
 │ - SWOT & GAP analysis
 │ - Feasibility checks
 └───────────────┬─────────────┘
                 ↓
 ┌─────────────────────────────┐
 │ Design                      │
 │ - Translate requirements
 │ - Use Case Diagrams & User Stories
 └───────────────┬─────────────┘
                 ↓
 ┌─────────────────────────────┐
 │ Implementation              │
 │ - Support development teams
 │ - Align build with business needs
 └───────────────┬─────────────┘
                 ↓
 ┌─────────────────────────────┐
 │ Testing & Validation        │
 │ - Traceability Matrix
 │ - UAT facilitation
 │ - Verify deliverables
 └───────────────┬─────────────┘
                 ↓
 ┌─────────────────────────────┐
 │ Closure                     │
 │ - Deployment support
 │ - Training & lessons learned
 │ - Final sign‑off
 └─────────────────────────────┘

```

✨ **Flow** — This chart shows the **continuous lifecycle** of a BA project: **Initiation → Planning → Analysis → Design → Implementation → Testing → Closure**. Each phase builds on the previous one, ensuring projects are **strategically aligned, technically feasible, and validated for business value**.
