## 📘 01 — **Methodology Overviews** & Planning Artifacts

- **Waterfall** → Linear, sequential phases; best for fixed-scope projects.

- **Agile** → Iterative, adaptive; suited for evolving requirements.

- **Scrum** → Sprint-based cycles with team accountability.

- **Kanban** → Visual boards for workflow optimization.

- **Hybrid** → Combines Agile flexibility with Waterfall predictability.

### **Key Planning Artifacts:**

- **Project Charter** → Defines objectives, stakeholders, and scope.

- **Work Breakdown Structure (WBS)** → Hierarchical task decomposition.

- **Gantt Charts** → Timeline visualization for tasks.

- **Risk Register** → Tracks risks, mitigation strategies.

- **Communication Plan** → Defines stakeholder information flow.

### **Control Tools (monitoring & execution):**

- **Deltek Acumen** → Schedule risk analysis & diagnostics.

- **Microsoft Project** → Task hierarchies, baselines, portfolio optimization.

### **Governance Tools (oversight & compliance):**

- **Smartsheet** → Dashboard-based stakeholder reporting.
