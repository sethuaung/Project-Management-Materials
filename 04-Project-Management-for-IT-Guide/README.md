# 📘 IT Project Management Framework Documentation

This repository contains structured guides and reference documents for **IT Project Management (ITPM)**. Each file provides a focused overview of methodologies, roles, artifacts, and lifecycle phases relevant to IT projects.

## 📂 Files Overview

### 1. **pm-ITPM-Framework.md**

-   Defines the **overall ITPM framework**
    
-   Explains integration of methodologies (Agile, Waterfall, Hybrid)
    
-   Outlines governance, planning artifacts, and performance alignment
    

### 2. **pm-ITPM-Infra-Glossary.md**

-   Glossary of **infrastructure-related terms** in IT projects
    
-   Covers cloud-native, microservices, DevOps, CI/CD, and networking concepts
    
-   Provides quick-reference definitions for classroom and project use
    

### 3. **pm-ITPM-Project-Env-Testing-Phases.md**

-   Explains **project environment setup** and **testing phases**
    
-   Includes unit, integration, system, UAT, and regression testing
    
-   Maps environments (Dev, QA, Staging, Production) to testing workflows
    

### 4. **pm-ITPM-Roles-in-IT-project.md**

-   Defines **key roles in IT projects**
    
-   Project Manager, Scrum Master, Product Owner, Developers, QA, Infra Engineers
    
-   Includes RACI (Responsible, Accountable, Consulted, Informed) matrix
    

### 5. **pm-ITPM-Soft-SDLC.md**

_(Software Development Life Cycle)_

-   Structured phases: Planning, Requirement Analysis, Design, Development, Testing, Implementation, Maintenance
    
-   Benefits: stakeholder alignment, risk reduction, scalability
    
-   Includes diagrams and PME classroom-ready mappings
    

### 6. **pm-ITPM-Soft-Test-STLC.md**

_(Software Testing Life Cycle)_

-   Phases: Requirement Analysis, Test Planning, Test Case Development, Environment Setup, Test Execution, Closure
    
-   Benefits: defect prevention, traceability, early validation
    
-   Includes visual workflows and bilingual quick-reference sheets
    

### 7. **pm-ITPM-Sys-SDLC.md**

_(System Development Life Cycle)_

-   Framework for **information system development**
    
-   Phases: Planning, Requirement Analysis, Design, Development, Testing, Implementation, Maintenance
    
-   Emphasis on system scalability, maintainability, and compliance
    

## 🎯 Usage

-   Ideal for **PME learners**, classroom deployment, and IT project teams
    
-   Provides **quick-reference charts**, **glossaries**, and **lifecycle diagrams**
